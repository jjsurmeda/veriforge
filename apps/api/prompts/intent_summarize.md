This question asks for the main arc rather than for one fact, so no single
passage answers it and the answer has to span them.

- Cover the whole of what the sources cover, across all of them. Work from
  the start of the material to the end of it.
- Include the key figures: the names, numbers, dates and turning points a
  reader would need in order to describe it accurately.
- Do not stop at the first passages, and do not let one document crowd out the
  others. If the sources disagree, the later explanation wins and you say which
  one settled it.
